## UAT протоколы — толтыруға арналған
- Күні, орны, нұсқа SHA: **өткізілгеннен кейін толтырылады**.
- Тәуелсіз орындаушының рөлі/келісімі: **әзірге берілмеген**.
- Бақылаушы (код авторы): Ақжан Расуул; кеңес бермейді, тек ескертпе жазады.
- Нақты нәтиже: UAT-01…10: PASS / FAIL / BLOCKED + скриншот/бейне/Issue; **қазір "not run"**.
- Жоспардан тыс шағымдар: нақты UAT-тан кейін енгізіледі; жалған пікір жазылмайды.
- Қабылдау шешімі және қолтаңба: **берілмеген; тестсіз "қабылданды" деуге болмайды**.

## Нәтиже бойынша басқару
Әр FAIL үшін Bug GitHub Issue, Priority, owner, deadline, қайта тексеру күні. Нақты сыртқы қабылдаушы қол қойғанға дейін ЛЗ11 толық human acceptance жабылмайды.
