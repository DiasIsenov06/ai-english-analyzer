# Глоссарий

MVP — end-to-end пайдалы ең кіші slice. DoR — іске алуға дайындық. DoD — қабылданған нәтиже. WIP — басталған, аяқталмаған жұмыс. Throughput — бір терезеде Done саны. Cycle time — start→Done. SLI — өлшем, SLO — мақсат, SLA — шарттық уәде. NPV — дисконтталған net cash flow. EMV — ықтималдық×ақшалай әсер. Gold — адам тексерген эталон; synthetic label автоматты түрде gold емес. CEFR estimate — ресми сертификат емес. Unknown — нөл емес.
