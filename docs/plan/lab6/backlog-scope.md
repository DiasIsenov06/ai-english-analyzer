# Болжамға кіретін көлем

Бастапқы артефакт — №4 жұмыстағы 18 user story және репозиторийдегі docs/plan/wbs.md. Функционалдық MVP: AEA-US-01–14; кейінгі R2: AEA-US-15–18.

data/lab6_backlog.csv файлында 14 жол бар. Қабылданған тарихтардың расталған тізімі болмағандықтан, бұл оқу сценарийінде accepted=False деп алынды: N = 14 − 0 = 14. Кодтың болуы оны қабылданды деп санауға жеткіліксіз. Бұл нақты ашық GitHub issue саны емес; әр ID талап идентификаторы.

Done: оң және теріс қабылдау сценарийі өтеді; дерек иелігі тексеріледі; өзгеріс review-дан өтеді; нәтиже мен дәлел тіркеледі. US-07 үшін нақты API-де 28 күн, US-08 үшін жарамды 28 күндік fallback қажет. Жоба коды осы жұмыста өзгертілмейді.

Қысқартылған нұсқа: US-11, US-12, US-13 жетілдірулері R2-ге өтеді; N=11. US-14 тек тест пен күнделікті тапсырма деректеріне шектеліп, US-13 тәуелділігі алынады. Қауіпсіздік, fallback және деректерді сақтау талаптары қалады.

ЛЗ5-тегі барлық WBS 110 сағат; соның 64 сағаты 14 функционалдық тарих, қалған 46 сағат дайындық, интеграция, сапа, миграция, оқыту мен тапсыру. Бұл 46 сағат 14 элементтік модельде жеке есептелмейді. Оларды story санына еркін аударуға болмайды; толық релизге бөлек қалдық пен capacity есебі қажет.
