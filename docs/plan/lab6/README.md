## Іске қосу

Репозиторийдің түбірінен:

```bash
python -m pip install -r notebooks/requirements-lab6.txt
python scripts/run_lab6.py
```

Немесе `jupyter lab` ашып, `notebooks/lab6_monte_carlo.ipynb` үшін Restart Kernel and Run All таңдаңыз. Қажет болса PyCharm-да scripts/run_lab6.py іске қосылады. Графиктер мен CSV/JSON docs/plan/lab6 ішінде сақталады. Интернет пен AI кілті есепке қажет емес. Кітапханалар бір рет орнатылады.

Тексеру: notebook-тың барлық код ұяшықтары таза Python кеңістігінде екі рет орындалды; forecast.json бірдей шықты. Қосымшаның функционалдық қабылдау сынақтары бұл жұмыста орындалған жоқ.
