# Pre-mortem — жеке талдау

Сценарий: «Семестр аяқталды, AI English Analyzer қабылданбады. Не болды?»

Бұл — код пен жоспарға сүйенген жеке талдау нәтижесі. 25 минуттық командалық кездесудің қатысушылары мен хаттамасы ретінде ұсынылмайды. Талқылауға арналған топтар:

1. Өнім қабылдауға сәйкес емес: 7/28 күн айырмасы, scope өзгерісі → R06, R17.
2. Дерек сенімсіз: API иелігі, болжамды кілт, браузер token-і, секрет → R01, R02, R11, R18.
3. Орта тұрақсыз: осал тәуелділіктер, ашық порттар, backup, жаңарту → R03, R05, R12, R16.
4. AI тәуелді: квота, қате кеңес, injection, кідіріс → R08, R09, R10, R19.
5. Пилотқа негіз жоқ: трансшекаралық беру, consent, retention, аудит → R04, R13, R14, R15.
6. Орындауға уақыт қалмады: оқу жүктемесі, жалғыз әзірлеуші → R07, R20.

Топтастырудан кейін 20 тәуекел қалды. Белгілі ақаулар I01–I10 ретінде бөлек тіркелді. Жеке талдау иесі — Ақжан Расуул; басқа адамдардың қатысуы немесе келісімі тіркелген жоқ.
