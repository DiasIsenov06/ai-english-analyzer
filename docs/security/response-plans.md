# Топ-5 тәуекелге жауап жоспары

Рейтинг EMV кемуімен, тең болғанда ID бойынша. Сағат — оқиға салдарын жою бағасы; алдын алу жұмысы бөлек жоспарланады.

## R01 — EMV 5.4 сағат

Егер бөгде адам plan API-дегі userId/dayId мәндерін қолданса, онда басқа адамның жоспары ашылады не өзгереді.

- Иесі: Ақжан Расуул; қайта қарау: 2026-10-16.
- Триггер: Иесіз GET/PATCH сұрауы 2xx қайтарады.
- Алдын алу: Қорғалмаған маршруттарды нақты деректен оқшаулау. Барлық GET/POST/PATCH үшін JWT тексеріп, userId-ді token-нен алу; DB query-ді owner арқылы шектеу.
- Қабылдау: Екі тест пайдаланушы: өз жоспары 200; token жоқ 401; бөгде жоспар 403/404; DB өзгермейді.
- Оқиға туғанда: Рұқсатсыз өзгеріс расталса, endpoint-ті уақытша жабу, аудитті сақтау, тексерілген backup-пен қалпына келтіру.
- Байланыс: SEC-01.

## R03 — EMV 3.6 сағат

Егер осал runtime тәуелділігінің қолданылатын жолы іске қосылса, онда қызмет тоқтап не дерек ашылып, қалпына келтіру қажет болады.

- Иесі: Ақжан Расуул; қайта қарау: 2026-10-18.
- Триггер: Runtime жолына қатысты CRITICAL/HIGH жазба ашық.
- Алдын алу: 74 жазбаның runtime/dev және reachability сипатын жіктеу; Next.js үшін қауіпсіз қолдау тармағына көшу; transitives-ті үйлесімді жаңарту.
- Қабылдау: Build және auth/plan/training smoke өтеді; CRITICAL/HIGH бойынша fix немесе мерзімді, дәлелді exception бар; Trivy қайта іске қосылған.
- Оқиға туғанда: Жаңарту регрессиясында соңғы тексерілген нұсқаға rollback және осал маршрутты шектеу.
- Байланыс: SEC-02.

## R06 — EMV 3.6 сағат

Егер 28 күндік жоспар қабылдауға жақын кезде ғана келісілсе, онда 7 күндік API-ді қайта жасау мерзімді ұзартады.

- Иесі: Ақжан Расуул; қайта қарау: 2026-10-16.
- Триггер: API duration_days=7, қабылдау талабы 28 күн болып қалады.
- Алдын алу: US-07/08 қабылдау шартын бекіту; генераторды 28 күнге біріктіру және транзакциямен жазу; R2 функцияларын бөлек ұстау.
- Қабылдау: 28 бірегей күн, әр күнде тапсырма; қате кезінде жартылай жазба жоқ; қабылдау дәлелі issue-де.
- Оқиға туғанда: Мерзім тұрақты болса, R2 жақсартуларын шығарып, MVP көлемін оқытушымен қайта бекіту.
- Байланыс: RAID follow-up.

## R04 — EMV 3.5 сағат

Егер нақты дерек шетелдік сақтау не LLM сервисіне негізсіз жіберілсе, онда пилот тоқтап, архитектураны өзгерту керек болады.

- Иесі: Ақжан Расуул; қайта қарау: 2026-10-21.
- Триггер: Нақты дерекке дейін орналасу/беру негізі бекітілмеген.
- Алдын алу: Дерек ағынын тізімдеу; ҚР сақтау аймағын нақтылау; провайдерге берілетін мәтінді азайту, негізін/келісімін және subprocessors тізімін бекіту.
- Қабылдау: Deployment аймағының дәлелі, келісім нұсқасы, дерек inventory және оқытушының пилотқа келісімі тіркелген.
- Оқиға туғанда: Негізі расталмаған сыртқы AI өңдеуін өшіру; тек синтетикалық сценариймен демо; жою/хабарлау қажеттігін бағалау.
- Байланыс: SEC-03.

## R02 — EMV 2.5 сағат

Егер JWT_SECRET орнатылмай орта іске қосылса, онда болжамды кілтпен жалған сессия жасалуы мүмкін.

- Иесі: Ақжан Расуул; қайта қарау: 2026-10-16.
- Триггер: Сервер JWT_SECRET жоқ кезде іске қосылады.
- Алдын алу: JWT fallback-ты жою; кемінде 32 кездейсоқ байт secret; missing config кезінде startup error; demo secret-пен production-ға жол бермеу.
- Қабылдау: Secret жоқта процесс старт алмайды; жарамсыз token 401; secret алмасқанда ескі сессия қайта кіре алмайды.
- Оқиға туғанда: Fallback нақты ортада қолданылса кілтті айналдыру, барлық ескі token-ді жарамсыз ету және оқиғаны тіркеу.
- Байланыс: SEC-01.
