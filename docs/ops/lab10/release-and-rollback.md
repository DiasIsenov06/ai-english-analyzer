## Rollback реті
0. Шешімді Ақжан Расуул **жеке, келісусіз**, 5 минутта қабылдайды.
1. Қате релизді тоқтату, бұрынғы жұмыс істейтін image ID табу: 3 минут.
2. Бұрынғы image тегіне оралып, docker compose up -d --no-build --force-recreate app: мақсат 5 минут.
3. scripts/smoke-lab10.sh және 3 сценарий: 10 минут.
4. DB schema өзгерсе кері миграция/тексерілген restore: мақсат 30 минут; **кепіл емес**, дерек жоғалту тәуекелі бар.
5. Инцидент/хабарлама: 10 минут; postmortem жоспарлау.

Нақты rollback орындалмады. Ескі Docker image-ті prune өшірмеуі керек.
